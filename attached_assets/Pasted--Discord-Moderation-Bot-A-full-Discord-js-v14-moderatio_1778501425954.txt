# Discord Moderation Bot

A full Discord.js v14 moderation and staff-network bot with 34 slash commands, SQLite persistence, role-based permissions, and a health endpoint for uptime monitoring.

## Bot Source Files — Detail

| File | Purpose |
|---|---|
| `src/index.js` | Starts the Discord client, registers all commands on startup, listens for interactions, tracks deleted messages for `/snipe`, counts messages for leaderboard, and runs a small Express server for the `/health` ping endpoint |
| `src/commands.js` | Every slash command in one file — warn system, ad-warn with message deletion, mute/ban/fire, strike system, jail/unjail, all four request commands (with image proof), and all utility commands |
| `src/setup.js` | The five `/setup*` commands that configure the bot per server — log channels, jail role, and per-command role permissions |
| `src/database.js` | Opens the SQLite database, creates all tables on first run, runs any column migrations, and exports every DB helper function used by commands |
| `src/utils.js` | Shared utilities: safe member/channel/role fetching that never throws, `parseDuration`, `formatDuration`, embed builders for warns/strikes/requests/ad-warns, permission checking, and log channel routing |

---

## Database Tables

| Table | Stores |
|---|---|
| `guilds` | Per-server config: log channels, jail role, and role lists for every command |
| `warns` | Warning records with case ID, user, moderator, reason, and timestamp |
| `ad_warns` | Ad warning records — also stores deleted message ID and full deleted message content |
| `strikes` | Strike records with case ID, user, moderator, and reason |
| `jailed_users` | Active jails — stores original role IDs for restoration on `/unjail` |
| `message_counts` | Per-user message count per server for `/messages` and `/message-leaderboard` |
| `snipe_cache` | Last deleted message per channel for `/snipe` |
| `balances` | Economy balance per user per server for `/balance` |
| `breaks` | Active staff breaks for `/current-breaks`, `/break`, `/break-end` |

## Health Endpoint

The bot runs a small HTTP server alongside Discord. Point UptimeRobot at:

```
https://bot-manager--mcgrayen8.replit.app/health
```
